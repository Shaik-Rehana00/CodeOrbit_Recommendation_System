CodeOrbit Recommendation System
Project Overview
This project is a simple movie recommendation syatem developed using python as part of the CodeOrbit tech AI Internship.
Features
. Recommends movies based on genre similarity.
. Uses a sample dataset of eight movies.
. Calculates similarity using the Jaccard similarity coefficient.
. Displays the top three recommendations.

Technologies Used
. Python
. Sets and dictionaries
. Jaccard similarity

How It Works

The used enters a movie title. The system compares its genres with other movies, calculates similarity scores, and displays the most similar movies.

How To Run

1. Install Python.
2. Open the project folder in a terminal.
3. Run python recommendation_system.py.
4. Enter a movie name when prompted.

Example
Input: Inception

Output: Movies such as Avengers, Avatar, and The Martian are recommended based on genre similarity.
